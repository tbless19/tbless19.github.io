# Prince Tawiah: Portfolio

Personal portfolio site: data science, systems engineering, and operations.

- **Main site:** `index.html` at the root (Aurora style, Slide section transitions).
- **Alternate styles:** `styles/` holds the other designs (Graph Paper, Editorial, Midnight, Swiss). They share the root `assets/` folder and are marked `noindex`.
- **Assets:** `assets/` contains the photo, both resume PDFs, and the resume preview images.

Plain HTML, CSS, and JavaScript with no build step. To preview locally, run `python3 -m http.server` in this folder and open http://localhost:8000.

Tip: press **L** on the main site.
